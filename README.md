---

## ✨ Nội Dung Nghiên Cứu

1. `01_data_audit.ipynb`: Kiểm thử và khám phá tập dữ liệu ảnh lá cây.
2. `02_dataset_balancing.ipynb`: Xử lý hiện tượng mất cân bằng dữ liệu (Imbalanced Data).
3. `03_baseline_cnn.ipynb`: Dựng mô hình Convolutional Neural Network (CNN) Baseline.
4. `04_mobilenet_transfer.ipynb`: Transfer Learning với kiến trúc MobileNetV2 tối ưu cho thiết bị di động.
5. `05_model_evaluation.ipynb`: Đánh giá Confusion Matrix, Precision, Recall, F1-Score.
